# ยืดดี

เว็บขายเสื้อยืด มีหน้าร้าน ตะกร้า สั่งซื้อพร้อมที่อยู่จัดส่ง (โอนพร้อมเพย์หรือเก็บเงินปลายทาง) และหน้าหลังร้านไว้ดูกับเปลี่ยนสถานะออเดอร์

## วิธีรัน

ต้องมี Python 3.8 ขึ้นไป ไม่ต้องติดตั้งอะไรเพิ่ม

```bash
cd shirt-shop
python3 server.py
```

- หน้าร้าน: http://localhost:8001
- หลังร้าน: http://localhost:8001/admin.html (รหัสเริ่มต้น `yuetdee`)

ตั้งรหัสแอดมินเองก่อนเปิดใช้จริง: `ADMIN_KEY=รหัสของคุณ python3 server.py`
เปลี่ยนพอร์ต: `PORT=3000 python3 server.py`

## แก้สินค้าและข้อมูลร้าน

แก้ใน `products.json` แล้วรีเฟรชหน้าเว็บ ไม่ต้องรีสตาร์ต

- `shop` ชื่อร้าน เบอร์พร้อมเพย์ LINE ค่าส่ง ยอดขั้นต่ำส่งฟรี ค่าเก็บปลายทาง
- `sizes` ตารางไซซ์ `[ไซซ์, รอบอก(นิ้ว), ความยาว(นิ้ว)]` แยกตามทรง
- `products` สินค้าแต่ละตัว
  - `shape` ทรงของรูป: `tee` `oversize` `polo` `long` `tank`
  - `fit` ใช้ตารางไซซ์ไหน: `regular` `oversize` `tank`
  - `print` ข้อความสกรีนบนอก ขึ้นบรรทัดใหม่ด้วย `\n` (เว้นว่างถ้าเป็นเสื้อเปล่า)
  - `colors` `[ชื่อสี, รหัสสี]`

รูปเสื้อวาดจากโค้ด (`static/shirt.js`) ถ้ามีรูปถ่ายจริงค่อยเปลี่ยนเป็น `<img>` ทีหลัง

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `server.py` | เว็บเซิร์ฟเวอร์และ API คิดราคาใหม่ฝั่งเซิร์ฟเวอร์ทุกออเดอร์ |
| `products.json` | สินค้าและข้อมูลร้าน |
| `orders.json` | ออเดอร์ (สร้างเองตอนมีออเดอร์แรก) |
| `static/index.html`, `app.js`, `style.css` | หน้าร้าน |
| `static/shirt.js` | วาดรูปเสื้อ |
| `static/admin.html` | หลังร้าน |

## ข้อจำกัด

- ยังไม่ได้ต่อระบบจ่ายเงินจริง ลูกค้าโอนเองแล้วส่งสลิปทาง LINE ร้านต้องเช็กยอดแล้วเปลี่ยนสถานะเป็น "รอจัดส่ง" เอง
- ไม่ได้ตัดสต็อก ถ้าของหมดให้ลบสีหรือไซซ์ออกจาก `products.json`
- ถ้าจะเปิดขายจริงบนอินเทอร์เน็ต ควรวางหลัง HTTPS (เช่น Render, Railway หรือ VPS + Caddy) เพราะมีที่อยู่และเบอร์โทรลูกค้า
