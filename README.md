# ก๊วนขาดขา

เว็บนัดเพื่อนตีแบด ก๊วนไหนขาดคนก็โพสต์ไว้ ใส่สนาม เวลา ระดับมือ (BG, N, S, P-, P, P+) ค่าคอร์ท และค่าลูก คนที่ว่างก็กดจอยได้เลย

## วิธีรัน

ต้องมี Python 3.8 ขึ้นไป (macOS มีมาให้แล้ว) ไม่ต้องติดตั้งอะไรเพิ่ม

```bash
python3 server.py
```

เปิด http://localhost:8000

เปลี่ยนพอร์ตได้ด้วย `PORT=3000 python3 server.py`

## ให้เพื่อนเข้าใช้

- **Wi-Fi วงเดียวกัน:** ดู IP เครื่องด้วย `ipconfig getifaddr en0` แล้วให้เพื่อนเปิด `http://<IP>:8000`
- **ผ่านอินเทอร์เน็ต:** เอาไปวางบนเซิร์ฟเวอร์ที่รัน Python ได้ เช่น Render, Railway, หรือ VPS

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `server.py` | เว็บเซิร์ฟเวอร์และ API เก็บข้อมูลลง `data.json` |
| `static/index.html` | หน้าเว็บ |
| `static/style.css` | หน้าตา (มีโหมดมืดตามเครื่อง) |
| `static/app.js` | โค้ดฝั่งเบราว์เซอร์ ดึงข้อมูลใหม่ทุก 10 วินาที |

## API

ทุกคำขอต้องมี header `X-Player-Id` (หน้าเว็บสร้างให้อัตโนมัติ เก็บไว้ในเบราว์เซอร์)

| Method | Path | ทำอะไร |
| --- | --- | --- |
| GET | `/api/sessions` | ดูก๊วนทั้งหมดที่ยังไม่ผ่านไป |
| POST | `/api/sessions` | ตั้งก๊วนใหม่ |
| DELETE | `/api/sessions/<id>` | ลบก๊วน (เฉพาะคนตั้ง) |
| POST | `/api/sessions/<id>/join` | จอยก๊วน `{nick, level}` |
| DELETE | `/api/sessions/<id>/join` | ยกเลิกจอย |

## ข้อจำกัด

- ยังไม่มีระบบล็อกอิน ระบบจำตัวผู้ใช้จากรหัสที่เก็บในเบราว์เซอร์ ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง จะลบก๊วนที่ตัวเองตั้งไว้ไม่ได้
- LINE ID ของคนตั้งก๊วนจะโชว์เฉพาะคนที่จอยแล้ว
- ก๊วนที่ผ่านวันไปแล้วจะถูกลบออกเอง
