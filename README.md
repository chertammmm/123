# 🏸 ตีด้วยกัน — หาเพื่อนตีแบด

เว็บสำหรับคนที่จองคอร์ทแล้วขาดคน เปิดนัดหาคนมาตีด้วย และหาเพื่อน/คู่ตีประจำจากโปรไฟล์ผู้เล่น

## ฟีเจอร์
- **สมัครสมาชิก / เข้าสู่ระบบ** ด้วยชื่อผู้ใช้และรหัสผ่าน (เก็บรหัสเป็น hash แบบ PBKDF2)
- **โปรไฟล์**: อวตาร, ระดับฝีมือ, ย่าน, วันและเวลาที่สะดวก, ช่องทางติดต่อ, แนะนำตัว และสถานะ "กำลังหาเพื่อนตี"
- **ค้นหาก๊วน**: สร้างนัด (ชื่อนัด สนาม วันเวลา ระดับ จำนวนคนที่ขาด ค่าคอร์ท) แล้วคนอื่นกด "เข้าร่วมก๊วน" ได้ ชื่อดึงจากโปรไฟล์ให้อัตโนมัติ กรองได้ตามพื้นที่ วัน ระดับ และช่วงเวลา ส่วนนัดที่เลยวันไปแล้วจะถูกลบเอง
- **นัดของฉัน**: นัดที่สร้าง นัดที่เข้าร่วม และนัดที่บันทึกไว้ รวมถึงปฏิทินรายสัปดาห์บนหน้าแรก
- **สนามแบด**: รวมสนามที่มีนัดเปิดอยู่
- **คอมมูนิตี้**: รวมผู้เล่นทั้งหมด กรองได้ตามระดับ ย่าน และวันที่ว่าง กดเข้าไปดูโปรไฟล์ได้
- ช่องทางติดต่อเห็นได้เฉพาะคนที่ล็อกอินแล้ว

## วิธีรัน
ต้องมี Python 3.9 ขึ้นไป และไม่ต้องติดตั้งอะไรเพิ่ม

```bash
python3 server.py          # เปิด http://localhost:8000
PORT=3000 python3 server.py  # เปลี่ยนพอร์ต
```

ข้อมูลทั้งหมดเก็บอยู่ใน `data.json` (ไม่เอาขึ้น git)

## โครงสร้าง
```
server.py         เซิร์ฟเวอร์ + API
static/index.html หน้าเว็บ (SPA ใช้ hash routing)
static/app.js     โค้ดฝั่งหน้าเว็บ
static/style.css  สไตล์ (รองรับมือถือและ dark mode)
```

## API
| Method | Path | หน้าที่ |
|---|---|---|
| POST | `/api/register` | สมัครสมาชิก |
| POST | `/api/login`, `/api/logout` | เข้าสู่ระบบ / ออกจากระบบ |
| GET / POST | `/api/me` | ดู / แก้ไขโปรไฟล์ตัวเอง |
| GET | `/api/players` | ผู้เล่นทั้งหมด |
| GET | `/api/players/<username>` | โปรไฟล์ + ก๊วนที่จะไป |
| GET / POST | `/api/posts` | ดู / สร้างก๊วน |
| POST | `/api/posts/<id>/join` · `leave` · `delete` | ขอร่วมตี / ยกเลิก / ลบ (เฉพาะเจ้าของ) |
